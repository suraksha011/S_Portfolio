01 INTERACTION

LEARNING / AUDIO / WEB

RiMorse ↗

MORSE CODE LEARNING PLATFORM

A three-mode Morse code trainer designed to make learning Morse code interactive rather than purely memorization-based.

The platform covers all 36 alphanumeric characters and supports real-time audio synthesis together with bidirectional text-to-Morse conversion.

VANILLA JAVASCRIPT HTML5 WEB AUDIO API
01 : 03 : 07

Precise dot / dash / gap timing ratios for authentic Morse playback.

02 EXPERIMENT

COMPUTER VISION / INTERACTIVE ART

Breath Mirror

GESTURE-DRIVEN INTERACTIVE ART INSTALLATION

A browser-based interactive art installation that transforms a webcam into a gesture- and breath-controlled fogged mirror.

Instead of conventional click or touch input, the experience uses touchless interaction, including pinch-to-erase and dual-hand capture.

JAVASCRIPT HTML5 CANVAS MEDIAPIPE HANDS WEBRTC WEB AUDIO API
100% CLIENT-SIDE

The entire experience runs in the browser with zero backend dependency.
